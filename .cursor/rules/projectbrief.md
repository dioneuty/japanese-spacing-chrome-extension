# Project Brief

## 프로젝트 개요
일본어 웹페이지의 본문 텍스트에 단어 단위 공백을 삽입해 가독성을 높이는 개인용 Chrome 확장 프로그램.

## 목적
일본어는 기본적으로 띄어쓰기가 없어 웹에서 읽기 어려운 경우가 많다. 번역 없이 원문을 유지하면서 시각적 구분만 추가한다.

## 핵심 목표
1. Manifest V3 기반 Chrome 확장으로 `activeTab`, `scripting` 권한만 사용
2. **Sudachi WASM TokenizeMode B**로 文節(한국어 어절에 가까운 단위) 경계 분석 후 공백 삽입
3. 팝업에서 현재 탭에만 '띄어쓰기 적용' / '원문 복원' 실행
4. 원본 텍스트 노드 저장 및 정확한 복원, 반복 적용 시 공백 중복 방지
5. 빌드 없이 HTML/CSS/JS만으로 로컬 설치 가능

## 범위
### 포함
- 팝업 UI (적용 / 복원 버튼)
- 콘텐츠 스크립트 DOM 순회 및 텍스트 노드만 수정
- 제외 영역: `input`, `textarea`, `contenteditable`, `script`, `style`, `pre`, `code`

### 제외 (초기 버전)
- 자동 적용 (페이지 로드 시)
- 사이트별 설정 / 옵션 페이지
- 외부 API·CDN 의존
- 빌드·번들러·TypeScript

## 비즈니스 가치
개인 학습·독해용 도구. 설치가 간단하고 프라이버시를 유지한다 (로컬 처리, 네트워크 요청 없음).
