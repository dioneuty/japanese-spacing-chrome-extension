# Product Context

## 해결하는 문제
- 일본어 웹페이지는 단어 사이 공백이 없어 긴 문장을 읽기 어렵다.
- 번역기를 쓰면 원문이 바뀌거나 의미가 달라질 수 있다.
- 기존 뷰어·확장 중 일부는 DOM 전체를 재작성하거나 외부 서버에 텍스트를 보낸다.

## 사용자 경험 목표
1. 확장 아이콘 클릭 → 팝업에서 버튼 한 번으로 현재 탭에 적용
2. 원문 복원도 한 번의 클릭으로 되돌림
3. 입력창·코드 블록 등 편집·표시용 영역은 건드리지 않음
4. 네트워크 없이 즉시 동작

## 주요 기능
| 기능 | 설명 |
|------|------|
| 띄어쓰기 적용 | Sudachi 文節(Mode B) 기준 공백 삽입 |
| 원문 복원 | 저장해 둔 원본 텍스트로 되돌림 |
| 중복 방지 | 이미 적용된 노드는 저장된 원문 기준으로 재처리 |

## 대상 사용자
일본어 웹 콘텐츠를 원문 그대로 읽되, 띄어쓰기 보조가 필요한 개인 사용자.
